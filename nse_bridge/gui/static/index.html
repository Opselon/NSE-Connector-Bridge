Connection configuration

The bridge dials out to your NSE Platform server (no inbound ports, firewall-friendly). Secrets are stored in the OS secret store and are never shown back — only a masked value is displayed; paste a new key to replace it.

Environment or server base URL changed — restart the bridge for the new environment to take effect.
