The official local client for NSE Platform · MetaTrader 5 ↔ Platform, secure by construction

One file. Your terminal. The Platform.

The Bridge is a self-contained Windows executable that attaches to your MetaTrader 5 terminal and communicates securely with NSE Platform over an outbound-only, authenticated WebSocket — no inbound ports, no admin rights, no runtime dependencies. All trading intelligence stays server-side; the Bridge is a thin, verified execution client.

Installer (per-user, no UAC)

Download NSE-MT5-Bridge-Setup-*.exe and run it. Upgrades in place; configuration and credentials are preserved.

Direct from GitHub (PowerShell)

$script = "$env:TEMP\nse-bridge-install.ps1"
Invoke-WebRequest "https://raw.githubusercontent.com/Opselon/NSE-Connector-Bridge/main/scripts/install.ps1" -OutFile $script
& $script -Channel Stable

Automation & service operation

NSE-MT5-Bridge.exe                     # desktop application (default)
NSE-MT5-Bridge.exe --console           # foreground console service, no GUI
NSE-MT5-Bridge.exe --gui none          # headless service mode

# Machine-readable status of the RUNNING bridge (loopback API):
NSE-MT5-Bridge.exe status --json
NSE-MT5-Bridge.exe health --json
NSE-MT5-Bridge.exe diagnostics --json
NSE-MT5-Bridge.exe mt5 list --json

One JSON document per command — stable envelope, UTC timestamps, predictable exit codes. See CLI_REFERENCE.md.

Security posture

  • Loopback-only local API by default; the mandatory X-API-Key protects every HTTP endpoint and the dashboard WebSocket.
  • API keys live in Windows Credential Manager (DPAPI fallback) — never in plaintext config, never in logs (redaction layer).
  • The MT5 password is never requested or stored — sign in through the terminal itself.
  • Outbound-only WSS with TLS enforced; updates verify SHA-256 (+ Ed25519 when the release-signing key is provisioned — fail-closed until then).
  • Demo-only execution: live/unknown account types are refused by both the Platform and the Bridge's contract tests.
